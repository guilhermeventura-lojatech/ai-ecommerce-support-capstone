# Frontend

Interface demonstrativa da Etapa 4, construída com React, Vite e TypeScript.

Recursos principais:

- chat conectado ao endpoint `POST /support/messages`;
- painel de explicabilidade e fontes;
- escalonamento humano simulado;
- dashboard fiel aos resultados sintéticos registrados;
- seção narrativa sobre problema, arquitetura, riscos e conclusão;
- estados de carregamento e indisponibilidade da API.

Consulte o `README.md` da raiz para instalação, execução e testes no PowerShell.
