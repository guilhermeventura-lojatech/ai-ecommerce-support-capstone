# Conclusão executiva

O cenário exige selecionar a tecnologia conforme a natureza da solicitação, e não aplicar IA generativa indiscriminadamente. Regras resolvem casos padronizados, classificação ajuda no roteamento e LLM controlado é reservado para situações com necessidade semântica. Exceções e respostas sem fundamentação devem ser encaminhadas a pessoas.

A recomendação é começar com uma prova de conceito usando dados sintéticos, critérios claros de avaliação e mecanismos de rastreabilidade antes de considerar produção.
