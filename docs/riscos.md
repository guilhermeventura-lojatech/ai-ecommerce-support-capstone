# Riscos e governança

| Risco | Impacto estimado no caso | Mitigação proposta |
| --- | --- | --- |
| Alucinação do LLM | Alto | Recuperação de conteúdo autorizado, validação e transferência humana |
| Interpretação incorreta de políticas | Alto | Base versionada de conhecimento e testes |
| Custo variável de API | Médio | Roteamento por regras e limites de consumo |
| Perda de confiança | Médio | Transparência e escalonamento |
| Injeção de prompt e abuso | Médio | Isolamento de instruções, testes adversariais e monitoramento |
| Privacidade de dados | Alto | Dados sintéticos no protótipo, mínimo acesso e revisão de LGPD |

Riscos classificados qualitativamente para discussão acadêmica; não constituem auditoria real.
